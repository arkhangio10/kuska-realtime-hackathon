# Guion (75 segundos)

1. Abrir KUSKA y señalar Piura (5 s).
2. Mostrar perspectiva y señal de Open-Meteo (10 s).
3. Votar una propuesta y observar el terreno común (10 s).
4. Publicar una propuesta concreta (10 s).
5. Pulsar “Encontrar propuesta puente” (15 s).
6. Votar el puente y revisar el plan de acción (15 s).
7. Recordar que agentes demo están etiquetados y que KUSKA no reemplaza especialistas (10 s).
